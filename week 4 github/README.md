# To-Do List Application

A simple task manager built with HTML, CSS and vanilla JavaScript (DOM manipulation).

## Features
- Add new tasks (button or Enter key), with empty-input validation
- Mark tasks as completed / pending
- Delete tasks
- Filter by All, Pending, Completed, with live counts
- Tasks are saved in the browser (localStorage)

## Files
| File | Purpose |
|------|---------|
| index.html | Page structure |
| style.css | Styling and responsive layout |
| script.js | Add, complete, delete, filter logic |
| screenshots/ | Output screenshots |

## How to run
1. Clone the repository: `git clone https://github.com/<your-username>/To-Do-List-Application.git`
2. Open `index.html` in any browser.
